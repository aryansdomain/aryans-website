IGCSE IDE

In August of 2026, I joined a new school following the Cambridge IGCSE curriculum, and took the Computer Science 0478 course.

This course required us to learn pseudocode, a programming language developed by the board, and flowchart design, using specific symbols and syntactical code inside them.

Cambridge offers a specification and details for the syntax of pseudocode and the design of flowcharts, but since this language was not very well-known outside of the Cambridge syllabus, there is no obvious, Cambridge-specific environment in which students can create, execute, and debug them, and receive immediate feedback.

Therefore, I developed the IGCSE IDE, an online website that allows students to run and debug pseudocode and flowcharts.

Since launch, the IDE has been used by more than 750 students, spanning 49 countries across 5 continents, and has recorded more than 16,000 code executions.
